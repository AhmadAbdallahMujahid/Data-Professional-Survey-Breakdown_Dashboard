# Data Professional Survey Dashboard

## Overview
This Power BI project analyzes survey data collected from data professionals across different roles, industries, and experience levels. The objective is to transform raw survey data into meaningful insights through data cleaning, modeling, and interactive visualizations.

The dashboard provides an overview of career trends, salary distribution, job satisfaction, work-life balance, programming language preferences, and other key metrics within the data profession.

---

## Project Objectives
- Clean and transform survey data using Power Query.
- Analyze responses from data professionals.
- Identify trends in salaries, job satisfaction, and career paths.
- Visualize insights through interactive dashboards.
- Create an intuitive report that supports data-driven decision-making.

- Data Cleaning

## Key Insights
Some of the insights that can be extracted from the dashboard include:

- Which data-related roles earn the highest salaries.
- The most popular programming languages among data professionals.
- Overall job satisfaction levels within the industry.
- Common challenges faced when entering the data field.
- Relationships between salary, experience, and job satisfaction.
